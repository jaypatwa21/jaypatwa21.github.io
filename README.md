# Jay Patwa — Portfolio

> Data Scientist · Data Analyst · Python Developer
> Ahmedabad, India

A premium, animated portfolio built with vanilla **HTML / CSS / JavaScript** — no frameworks, no build step. Editorial dark theme with custom cursor, preloader, magnetic interactions, scroll reveals, and a bento-grid About section.

**Live site:** https://jaypatwa21.github.io

---

## ✨ Features

- **Custom cursor** with morphing ring and contextual labels (View, Open, Copy, Mail…)
- **Preloader** with animated name reveal and progress bar
- **Floating dock navigation** with magnetic hover and active-section tracking
- **Top status bar** — live IST clock, "Open to Work" pulse, location
- **Hero** — word-by-word headline reveal with editorial serif accents, portrait with parallax tilt, floating tech badges, pull-quote card
- **Marquee strip** of tech keywords scrolling between sections
- **Bento grid** About section — animated CGPA counter, mini SVG location map, language proficiency bars
- **Skills board** — every chip is click-to-copy
- **Asymmetric project layout** with mock data visualizations (animated bar chart, KPI cards, scatter plot with trendline, tech-stack list)
- **Editorial timeline** with hover-shift rows
- Massive contact section with full-width email link, 4-column contact grid, and a huge fading "JAY PATWA" backdrop
- **Scroll progress bar**, animated mesh blob background, subtle grid + film grain
- `prefers-reduced-motion` support, full mobile responsive

## 🚀 Run Locally

No build step. Just open the file:

```bash
git clone https://github.com/jaypatwa21/jaypatwa21.github.io.git
cd jaypatwa21.github.io
# Option 1 — open directly
start index.html              # Windows
# Option 2 — serve locally (recommended, for fonts/CV path)
python -m http.server 8080
# then visit http://localhost:8080
```
